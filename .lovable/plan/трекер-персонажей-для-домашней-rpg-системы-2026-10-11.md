# Трекер персонажей для домашней RPG-системы

Перенос приложения из `app_2.py` (Streamlit) в веб-приложение. Правила игры и все таблицы переносятся без изменений.

## Принятые допущения (вопросы остались без ответа)
- Хранение: в браузере на устройстве (без входа). Позже можно перейти на облако со входом. Плюс экспорт и импорт персонажа в JSON-файл как резервная копия.
- Редактор при создании ведёт себя как в исходнике: уровни от -2 до 4, распределяются и основные, и вторичные, бонус в основную характеристику от навыков не начисляется, «прогресс» обнуляется.
- Кнопки «Отменить» нет: опыт можно убрать вручную.

## Структура данных

```text
Character {
  id, name, race, characterClass, avatar (картинка, сжатая до ~256px)
  primary:   { [Сила..Харизма]: { level, subIndex, progress } }
  secondary: { [навык]:         { level, subIndex, progress } }
  log:   [{ id, at, text }]        — история
  notes: [{ id, at, text }]        — заметки
  inventory: []                    — задел на будущее
  createdAt, updatedAt
}
```
Файл совместим с форматом JSON из исходника (поля `primary`, `secondary`, `log`, `notes`, `inventory`, `icon`), чтобы старых персонажей можно было импортировать.

## Игровая логика (отдельный модуль, без интерфейса)
- Таблицы: опыт для основных (-6..9, 5 подуровней), для вторичных (-5..10, 3 подуровня), бонусы HP, расы, классы, группы навыков.
- `addPrimaryExp` / `addSecondaryExp` — точная копия алгоритмов: перенос остатка между подуровнями, потолки (основные: 10 — остановка с обнулением прогресса; вторичные: на 10/3 прогресс держится на максимуме), откат вниз при снятии опыта, нижние пределы.
- Бонус: когда навык меняет уровень, за каждый пройденный уровень основная характеристика получает \(\mathrm{round}(\text{сумма строки}/3)\) опыта (или теряет при понижении). Округление как в Python (банковское).
- HP = раса + класс + бонус(Телосложение) + бонус(Стойкость) + бонус(Сила).
- КБ = 10 + уровень Ловкости.
- Уровень персонажа = сумма уровней всех характеристик и навыков.
- Каждое изменение пишет запись в историю с текстом как в исходнике.
- Тесты на правила: переход подуровня, перенос остатка, потолок, снятие опыта, бонус от навыка, HP, КБ, стоимость в редакторе.

## Экраны
1. **Список персонажей** — карточки (аватар, имя, раса/класс, уровень, HP, КБ), кнопки «Создать», «Импорт», удаление с подтверждением.
2. **Создание / редактирование** — имя, раса, класс, аватар; счётчик «осталось из 1000»; плюс/минус по характеристикам и навыкам (по группам); «Сбросить опыт»; создать нельзя, пока опыт не распределён полностью и нет имени; имя должно быть уникальным. В режиме редактирования меняются только имя, раса, класс и аватар.
3. **Персонаж** — шапка (аватар, имя, уровень, HP с разбивкой, КБ), вкладки:
   - **Характеристики** — 6 карточек с цветом и иконкой, уровень, подуровень, полоса прогресса; внутри карточки — её навыки. Нажатие открывает окно: ввод числа, быстрые кнопки (+10, +50, +100, −10…), «Добавить» / «Убрать».
   - **История** — лента событий, новые сверху, с датой.
   - **Заметки** — добавление, редактирование, удаление.
   - **Инвентарь** — оформленная заглушка «скоро».
   - Меню: редактировать, экспорт JSON, удалить.

## Дизайн
Тёмный фон с тёплым оттенком, золотые акценты и рамки, заголовки шрифтом Cormorant / Cinzel, текст — удобный шрифт без засечек. На телефоне — одна колонка, вкладки внизу экрана, крупные кнопки; на компьютере карточки в 2–3 колонки.

## Порядок работы
1. Модуль правил + тесты (сверка с исходником).
2. Хранение в браузере, импорт/экспорт.
3. Оформление (цвета, шрифты).
4. Список персонажей.
5. Редактор создания.
6. Экран персонажа: карточки и окно опыта.
7. История, заметки, заглушка инвентаря.
8. Проверка на телефоне и на компьютере, заголовки страниц.

## Технические детали
- Маршруты: `/` (список), `/new`, `/character/$id`, `/character/$id/edit`.
- `src/lib/rules/` — таблицы и чистые функции; `src/lib/storage.ts` — localStorage с проверкой данных при загрузке (как `from_dict`: ограничение диапазонов, пропуск битых полей); чтение только после загрузки страницы, чтобы не было рассинхронизации.
- Тесты — vitest рядом с существующими.
