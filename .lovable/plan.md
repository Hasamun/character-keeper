# Доработки трекера: HP, создание, заметки, инвентарь

## 1. Скрыть здоровье
- Убрать HP с листа персонажа: плашку «HP» и строку с разбивкой под шапкой. Остаются «Уровень» и «КБ».
- Убрать HP и из карточек в списке героев, чтобы значение нигде не было видно.
- Сам расчёт HP остаётся в правилах (и в тестах) — его можно будет вернуть позже.

## 2. Создание персонажа с остатком опыта
- Создать персонажа можно в любой момент, если свободный опыт 0 или больше.
- Если опыт остался (больше 0), при нажатии «Создать» появляется окно: «Осталось X опыта. Вы уверены, что хотите создать персонажа?» с кнопками «Создать» и «Отмена».
- Если свободный опыт ушёл в минус, «Создать» блокируется с подсказкой «Перерасход X опыта — понизьте другие характеристики».

## 3. Исправление ошибки со свободным опытом
- Свободный опыт больше не считается «шагами» прибавления и вычитания — он каждый раз пересчитывается заново из текущих уровней:
  свободный опыт = 1000 − стоимость всех купленных подуровней + возврат за подуровни ниже 0.
- Из-за этого никакая последовательность «повысить → понизить» (включая навыки и их бонус в основную характеристику) не может дать опыта больше, чем реально вернули уровни.
- Как вы описали: понижение ниже 0 возвращает опыт (для фокуса на других характеристиках), «+» можно нажимать и при нехватке — свободный опыт уходит в минус, но создать героя нельзя, пока он не станет 0 или больше.
- Пределы уровней при создании остаются от −2 до 4.
- Бонус от навыков в основную характеристику при создании не начисляется (как в исходнике); на уже созданном персонаже он работает как раньше.
- Тесты: повысить навык и понизить обратно — опыт ровно 1000; любые серии нажатий не дают больше, чем 1000 + возврат за уровни ниже 0; перерасход блокирует создание.

## 4. Кнопки быстрого опыта
- В окне добавления опыта: +1, +5, +25, +100.

## 5. Заметки с темой
- У заметки два поля: «Тема» и «Текст». Тема показывается заголовком карточки, редактируется вместе с текстом.
- Старые заметки без темы показываются с темой «Без темы».

## 6. Вкладка «Инвентарь»
Три блока, в том же тёмно-золотом стиле.

**Деньги** — четыре поля: Медь, Серебро, Золото, Платина. Можно ввести число или прибавить/отнять.

**Экипировка** — сетка слотов: Шлем, Нагрудник, Наручи, Перчатки, Поножи, Ботинки, Серьги, Амулет, Кольцо 1, Кольцо 2, Пояс.
- Оружие: два комплекта (А — в руках, Б — за спиной), в каждом «Основная рука» и «Вторая рука / щит». Кнопка «Сменить оружие» меняет активный комплект местами; неактивный показан приглушённо.
- Нажатие на пустой слот открывает список подходящих предметов из сумки; на занятый — «Снять».
- Пояс: предмет-пояс имеет вместимость от 1 до 4. Когда он надет, под ним появляется столько же ячеек быстрого доступа, куда кладутся только расходники. Если снять пояс, расходники возвращаются в сумку.

**Сумка (список предметов)**
- Фильтр: Все / Снаряжение / Расходники / Прочее.
- Кнопка «Добавить предмет»: название, категория, для снаряжения — какой слот занимает (шлем, нагрудник, …, кольцо, оружие, щит/вторая рука, пояс + вместимость), количество, описание.
- У предмета: изменить, удалить, «Надеть» (для снаряжения) / «На пояс» (для расходников). Надетые помечены значком.
- Удаление надетого предмета сначала снимает его со слота.
- Изменения инвентаря пишутся в «Историю» (надел, снял, сменил оружие, деньги).

## Технические детали
- `Character` получает поле `inventory` новой структуры: `{ money: {copper, silver, gold, platinum}, items: Item[], equipped: Record<SlotId, itemId|null>, weaponSets: [{main, off}, {main, off}], activeSet: 0|1, belt: (itemId|null)[] }`; `Item = { id, name, category: "gear"|"consumable"|"misc", slot?, beltCapacity?, quantity, description }`. Старый массив `inventory` при загрузке превращается в пустую структуру.
- Логика инвентаря (надеть/снять, проверка слота, смена оружия, пояс) — чистые функции в `src/lib/rules/inventory.ts` с тестами; интерфейс — отдельный компонент вкладки.
- Редактор создания: `computeFreeExp(character)` в правилах вместо счётчика в состоянии; `editorAdjust` больше не проверяет нехватку опыта, только пределы −2..4.
- `Note` получает поле `title`; нормализация при загрузке добавляет пустую тему.
